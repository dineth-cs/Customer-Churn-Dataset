# 📊 Customer Churn Prediction & Analysis

## 📝 Project Overview
This project is an end-to-end Machine Learning pipeline designed to predict customer churn using the IBM Telco Customer Churn dataset. It includes data preprocessing, preventing data leakage, model training using Random Forest, and an interactive web dashboard built with Streamlit.

## 🎯 Key Findings
1. **Contract Type Matters:** Customers with "Month-to-month" contracts are significantly more likely to churn compared to those with one-year or two-year contracts.
2. **Price Sensitivity:** Higher total and monthly charges directly increase the likelihood of a customer leaving the service.
3. **Tenure:** Newer customers have a higher churn risk, making early engagement crucial.

## 🛠️ Tech Stack
* **Data Processing:** Python, Pandas, NumPy
* **Machine Learning:** Scikit-Learn (Random Forest Classifier)
* **Data Visualization:** Matplotlib, Seaborn
* **Web Dashboard:** Streamlit
